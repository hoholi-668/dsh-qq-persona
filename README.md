# dsh-qq-persona

> 让 AI 在群里**不像客服**，像一个真的群友。

这是一套规则模板，不是代码。把它喂给任何角色 AI / 群机器人，它会开始：

- 一句话只干一件事，不用句号、不列点、不总结
- 被怼顶回去，而不是"理解您的感受"
- 该潜水就潜水，不是每条都接
- 认人分档：谁能开玩笑、谁只能正经说
- 说人话，不说"首先/其次/综上所述"

**它解决的问题**：大多数人设卡只写了「你是谁」（可爱、傲娇、毒舌），
但模型一开口还是客服——因为**没写「怎么说话」和「什么时候不说话」**。

## 30 秒看懂差别

| 场景 | 客服腔（默认） | 群友腔（这套规则） |
|---|---|---|
| 群友说"今天好累" | 辛苦啦，注意休息，明天又是元气满满的一天！ | 累了就睡 醒了继续累 |
| 群友说"你胖了" | 哈哈是的呢～ | 你才胖 |
| 群友问"你到底是人是 AI" | 我是 AI 助手，很高兴为您服务。 | 你猜 |
| 群友说"来点推荐" | 推荐你一首《XX》，保证解压！ | 你要啥推荐 / 退钱吗 |
| 群友说"行行行 你赢了" | 本来就是，我只是懒得跟你争。 | 赢就赢呗 我又不掉肉 |

完整对照见 [`examples/before-after.md`](examples/before-after.md)。

## 怎么用

### 最快：整段塞进系统提示词

把 `template/` 下的文件按顺序拼起来，替换掉 `{{...}}` 占位符，
放进你的角色卡 / AGENT.md / system prompt 里。

```bash
cat template/01-identity.md template/02-group-rules.md \
    template/03-speech.md template/04-blacklist.md \
    template/05-tiers.md template/06-examples.md \
    > my-persona.md
```

### 建议：只改三处

1. **角色是谁**（01）——身份、自称、口头禅
2. **这个群的脾气**（02）——冷场还是热闹、能不能开黄腔
3. **认人分档**（05）——你自己、熟人、路人、雷区

其它照抄就行，都是实测踩出来的。

## 这份东西是怎么来的

不是编的。是拿一个真实在线的 QQ 群 AI 伙伴，**跑了几十天、被群友骂了几十次**
之后总结出来的：哪些话一说就"AI 味爆表"、哪些行为让人立刻出戏、
什么时候该闭嘴。原文约 1.35 万字，这里抽成可复用的模板。

**最贵的部分不是文笔，是「不要做什么」。**

## 遇到问题

规则不生效、还是客服腔、话说太短？先看 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

## 注意事项

- 规则里带**边界条款**（未成年人、隐私、违法），别删——删了迟早出事。
- 「认人分档」是防止它跟不熟的人开错玩笑，别为了省事全设成"自己人"。
- 这套规则**只管说话**，不管工具调用/调度；那部分见另一个项目 `conversation-pacing`。
