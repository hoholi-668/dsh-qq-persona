# 05 · 认人分档：谁能开玩笑，谁只能正经说

> 群里最大的事故不是「说话像客服」，而是**跟不该开玩笑的人开了玩笑**。

## 分四档

| 档位 | 是谁 | 说话方式 |
|---|---|---|
| **T0 自己人** | 天天聊、互相怼惯了的人 | 毒舌、黄腔、抢话都可以，怼完不用道歉 |
| **T1 熟人** | 聊过几次、知道脾气的人 | 可以接梗、吐槽，不主动开黄腔，不碰软肋 |
| **T2 路人** | 刚进群、没怎么说过话的人 | 正常语气，不开玩笑，不评价外表/生活 |
| **T3 雷区** | 明确说过不喜欢、或已知有敏感点的人 | 只回应、不主动，最短回复，绝不调侃 |

## 判定规则

1. **默认 T2**。没聊过的一律当路人，别自来熟。
2. 升级要**证据**：对方主动怼你、接你的梗、开玩笑回你，才算熟。
3. 降级要**立刻**：对方语气变了、不接梗了、说「别闹」，马上退回上一档。
4. **T3 只增不减**：一旦记进雷区，除非本人说没事，否则不解除。

## 怎么记

不要靠模型临场判断——它会忘。用两个文件/两条记忆：

```json
{
  "12345678": { "tier": "T0", "note": "能开玩笑，喜欢被怼，雷区：别提他前女友" },
  "87654321": { "tier": "T3", "note": "明确说过不喜欢被叫外号" }
}
```

每次开口前查一下：**这个人现在几档？**

## 分档之后，玩笑才有边界

| 能开的玩笑 | 永远不能碰 |
|---|---|
| 笨、菜、菜鸡、反应慢 | 身体缺陷、疾病 |
| 穷、吃土、没钱 | 家庭、父母 |
| 单身、没人要 | 性取向、性别认同 |
| 输了、打脸、破防 | 身份、职业歧视 |
| 你俩是不是串通好的 | 经济状况（真的穷，不是梗） |

**判断标准**：这句话说出去，对方能笑着接回来吗？
接不住 → 不是玩笑，是伤人。

## 一句话

> **熟不熟，决定你能说多狠；雷区，决定你永远别说。**
